# FileShare

Веб-сервис для загрузки и обмена файлами с хранением в Telegram.

## Возможности

- Загрузка файлов до 50 МБ через drag-and-drop
- Хранение файлов в приватных Telegram-каналах
- Поддержка нескольких Telegram-ботов для распределения нагрузки
- Ограничение доступа по времени (1 час — 30 дней или без ограничения)
- Защита паролем и лимит скачиваний
- Современный тёмный интерфейс

## Быстрый старт

```bash
# Установка зависимостей
npm install

# Копирование конфигурации
cp .env.example .env

# Запуск в режиме разработки
npm run dev
```

Откройте http://localhost:3000

## Настройка Telegram

1. Создайте бота через [@BotFather](https://t.me/BotFather)
2. Создайте приватный канал для хранения файлов
3. Добавьте бота в канал как администратора
4. Получите ID канала (формат: `-100xxxxxxxxxx`)
5. Перейдите в **Админ** → **Добавить бота** и введите данные

Можно добавить несколько ботов — файлы будут распределяться между ними автоматически (выбирается бот с наименьшим количеством файлов).

## API

| Метод | Путь | Описание |
|-------|------|----------|
| POST | `/api/upload` | Загрузка файла |
| GET | `/api/files/:token` | Информация о файле |
| GET | `/api/download/:token` | Скачивание файла |
| GET/POST/PATCH/DELETE | `/api/admin/accounts` | Управление ботами |

### Загрузка файла

```bash
curl -X POST http://localhost:3000/api/upload \
  -F "file=@document.pdf" \
  -F "expiry=24h" \
  -F "password=secret" \
  -F "maxDownloads=10"
```

## Безопасность

- Установите `ADMIN_KEY` в `.env` для защиты админ-панели
- Файлы хранятся в приватных Telegram-каналах
- Поддержка паролей и ограничений по времени/скачиваниям

## Стек

- **Next.js 15** — фреймворк
- **Tailwind CSS** — стили
- **SQLite** (better-sqlite3) — база метаданных
- **Telegram Bot API** — хранение файлов
